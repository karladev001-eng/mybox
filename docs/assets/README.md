# Documentation Assets

Contains curated visual assets referenced by first-party documentation.

- `mybox-system-overview.png`: generated conceptual overview of the current
  MyBox Host/App boundaries and explicitly marked future adapters.
- `mybox-wordmark.png`: MyBox mark plus wordmark in dark ink on transparency,
  for documentation read on a light background.

The Markdown/Mermaid source in `../system-overview.md` remains authoritative for
exact labels and relationships; raster assets are explanatory views.
